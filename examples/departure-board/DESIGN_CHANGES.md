# Departure Board Design Changes

## 문서 목적

이 문서는 `examples/departure-board` 화면에서 지금까지 반영한 디자인 변경사항을 정리한 기록이다.
목표는 다음 두 가지다.

- 현재 화면이 어떤 기준으로 구성되어 있는지 빠르게 공유하기
- 다음 수정 때 디자인 기준점을 잃지 않기

## 전체 레이아웃 변경

### 1. 상단 Hero 영역 제거

- 기존 상단 소개 영역은 삭제했다.
- 화면에 들어오면 바로 `운영 패널`과 `출발 전광판`이 보이도록 단순화했다.

### 2. 루트 레이아웃 폭 확대

- `layout-grid`의 전체 사용 폭을 넓혔다.
- 바깥 여백과 패딩을 줄여서 실제 콘텐츠가 화면을 더 많이 쓰도록 조정했다.
- 현재 구조는 왼쪽 `운영 패널`, 오른쪽 `출발 전광판`의 2열 레이아웃이다.

### 3. 형제 패널 구조로 정리

- 루트 `DepartureBoardApp` 아래에서 `ControlPanel`과 `BoardScreen`을 형제로 배치했다.
- 시각적으로도 왼쪽은 입력/제어, 오른쪽은 표시 전광판 역할이 분명하게 나뉘도록 유지했다.

## 컴포넌트 구조 변경

### 1. 운영 패널 세분화

- `ControlPanel`
- `ControlForm`
- `RegisteredDeparturesList`
- `RegisteredDepartureCard`

운영 패널은 입력 폼과 등록 목록을 분리해서 읽기 쉽게 만들었다.

### 2. 전광판 세분화

- `BoardScreen`
- `BoardToolbar`
- `DepartureList`
- `StatusFilterHeadCell`
- `StatusFilterOverlay`
- `StatusBadge`

전광판은 상단 정보 영역과 표 영역을 분리했고, 상태 필터는 전용 헤더 셀과 오버레이 컴포넌트로 분리했다.

## 전광판 디자인 변경

### 1. 제목 위치 변경

- `출발 전광판` 제목은 전광판 패널의 상단 중앙에 배치했다.
- 제목이 보드의 중심 제목처럼 보이도록 정렬을 통일했다.

### 2. 상단 정보 영역 재배치

- `현재 시각`
- `전광판 계산`

이 두 정보는 좌우 병렬이 아니라 상하 2줄 구조로 배치했다.
긴 텍스트나 요약 숫자가 있어도 패널 밖으로 밀리지 않는 쪽을 우선했다.

### 3. 상태별 카운트 강조

- `정시`, `탑승 안내`, `지연`, `출발 완료` 카운트는 상태 배지와 같은 계열 색을 사용한다.
- 전광판 계산 줄에서 상태 색과 숫자 의미가 바로 연결되도록 맞췄다.

### 4. 컬럼 구성 정리

- `종류` 컬럼은 제거했다.
- 현재 표 컬럼은 다음 기준으로 유지한다.
  - `편명/열차`
  - `출발 시각`
  - `목적지`
  - `게이트`
  - `상태`
  - `남은 시간`

### 5. 상태 필터 UI 변경

- 상태 필터는 별도 select 줄을 두지 않는다.
- 표 헤더의 `상태` 제목 옆 아이콘을 누르면 필터 메뉴가 뜨도록 바꿨다.
- 필터 메뉴는 레이아웃 공간을 차지하지 않는 `overlay` 방식이다.
- 즉, 필터를 열어도 헤더 row 높이가 바뀌지 않도록 했다.
- 메뉴는 아이콘 바로 아래에 뜨고, 높은 `z-index`를 사용해 표 위에 겹쳐 보이도록 맞췄다.

### 6. 필터 아이콘 변경

- 임시 텍스트/이미지 느낌 대신 리스트 스타일의 아이콘을 사용한다.
- 아이콘은 헤더 액션 버튼처럼 보이도록 작은 사각 버튼 안에 배치했다.

## 운영 패널 디자인 변경

### 1. 설명성 문구 정리

- 학습용 설명 문구 중 화면을 복잡하게 만드는 텍스트는 제거했다.
- 운영 패널은 입력과 제어 기능 중심으로 보이도록 정리했다.

### 2. 등록 목록 스크롤 처리

- `현재 등록된 편성` 영역은 카드가 많아질 때 스크롤되도록 변경했다.
- 패널 전체 높이가 계속 늘어나지 않게 하고, 리스트 탐색을 안정적으로 유지한다.

### 3. 입력 레이아웃 보정

- `출발 시각`과 `지연(분)` 입력이 겹치지 않도록 폭을 조정했다.
- 작은 숫자 입력 필드는 더 좁게 잡아 공간 충돌을 줄였다.

### 4. 버튼 톤 유지

- `새로운 편성 추가` 버튼은 기존의 진한 파란색 주요 액션 톤을 유지한다.
- 운영 패널에서 가장 중요한 액션 버튼으로 보이도록 다른 버튼과 구분했다.

## 제거하거나 숨긴 요소

### 1. 제거한 요소

- `hero` 영역
- `hook-legend` 관련 UI
- `board-list-caption` 관련 UI
- 화면 내 보조 설명 문구 일부

### 2. 숨긴 요소

- `Hook Debug Panel`은 삭제하지 않고 임시로 숨김 처리했다.
- 필요하면 나중에 다시 노출할 수 있다.

## 상호작용 기준

### 1. 상태 필터

- `전체`
- `정시`
- `탑승 안내`
- `지연`
- `출발 완료`

필터를 바꾸면 전광판 표는 해당 상태의 행만 보여준다.

### 2. 남은 시간 표시

- `남은 시간`은 별도 캐싱 값이 아니라 화면 렌더 시 함수 계산으로 표시한다.
- 파생 표현값이므로 테이블에서 직접 계산하는 쪽으로 단순화했다.

### 3. 자동 판정 버튼

- 운영 패널의 `자동 판정` 버튼은 수동 상태 강제를 해제하고 시간 기준 자동 상태로 되돌리는 용도다.
- 이미 자동 상태인 항목은 비활성화되도록 조정했다.

## 현재 화면 확인 포인트

- 상단에 Hero 없이 바로 2열 레이아웃이 보이는지
- `출발 전광판` 제목이 보드 상단 중앙에 있는지
- `현재 시각`, `전광판 계산`이 상하 2줄로 보이는지
- `상태` 헤더 아이콘 클릭 시 메뉴가 헤더를 밀지 않고 겹쳐서 뜨는지
- 등록된 편성 카드가 많아지면 왼쪽 목록만 스크롤되는지
- `종류` 컬럼이 없는지
- Hook Debug Panel이 화면에 보이지 않는지

## 다음 수정 시 참고

- 필터 메뉴는 현재 `overlay` 방식이므로 위치 미세 조정은 아이콘 기준 좌표 계산만 건드리면 된다.
- 전광판은 학습용 예제라서 시각 요소보다 구조와 상태 흐름이 더 중요하다.
- 따라서 새 디자인 수정도 `ControlPanel / BoardScreen`의 역할 분리를 유지하는 방향이 좋다.
